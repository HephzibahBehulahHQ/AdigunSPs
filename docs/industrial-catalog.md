# Industrial product catalog

## Verified coverage

The reference catalog contains **10225 unique manufacturer product variants**: 4,902 Finder, 4,640 Doepke, 645 Siemens, 28 OMRON E3Z photoelectric sensor variants, three Schneider Electric products, and seven Phoenix Contact products. Siemens references include 163 rows from the official [SIMATIC S7-1200 product overview](https://mall.industry.siemens.com/tstcloud/Api/Catalog/ExportInformation?catalogItemId=S7_1200&lang=en), exported 2025-10-02; 75 rows from the [SIMATIC S7-1500 product overview](https://mall.industry.siemens.com/tstcloud/Api/Catalog/ExportInformation?catalogItemId=S7_1500&lang=en), exported 2024-09-29; 96 rows from the [SIMATIC ET 200SP product overview](https://mall.industry.siemens.com/tstcloud/Api/Catalog/ExportInformation?catalogItemId=ET200_SP&lang=en), exported 2025-10-14; 70 ET 200SP base units and bus adapters from the same export; and 58 rows from Siemens' [LOGO! 8 product overview](https://mall.industry.siemens.com/tstcloud/Api/Catalog/ExportInformation?catalogItemId=LOGO8&lang=en), exported 2025-10-08. The catalog also includes 23 interface and I/O modules, 36 ET-Connection cables, and 34 M8 supply cables from the [Siemens SIMATIC ET 200AL product overview](https://mall.industry.siemens.com/tst/Api/Catalog/ExportInformation?catalogItemId=ET200_AL&lang=en), exported 2025-10-10. These overview rows carry manufacturer-listed functions and exact order codes; they do not infer ratings or pin layouts and do not establish current availability. Every entry has a manufacturer identifier, product family, attributes, an HTTPS source, retrieval date, and explicit simulation status and limitations. The in-app catalog supports text search and shows source links. Product references remain read-only and cannot be placed as supported simulated devices.

The S7-1500 references cover CPU, digital I/O, analog I/O, communications, technology modules, and power supplies using the official 2024 export. Existing S7-1200 module, sensor, Schneider, and Phoenix product citations remain listed below. Sensor model, distance, connection, pinout, supply, and output-current data come from the [OMRON E3Z datasheet](https://assets.omron.eu/downloads/latest/datasheet/en/e3z_compact_photoelectric_sensor_with_built-in-amplifier_datasheet_en.pdf?v=7). Other sources are the [Schneider TM221CE24R page](https://www.se.com/us/en/product/TM221CE24R/logic-controller-modicon-m221-24-io-relay-ethernet/), [LC1D09B7 product page](https://www.se.com/us/en/product/LC1D09B7/iec-contactor-tesys-deca-nonreversing-9a-5hp-at-480vac-up-to-100ka-sccr-3-phase-3-no-24vac-50-60hz-coil-open-style/), [LRD12 datasheet](https://iportal.se.com/Contents/docs/SQD-LRD12_DATA%20SHEET.PDF), [Phoenix Contact QUINT4-PS product data](https://www.phoenixcontact.com/en-us/products/power-supply-quint4-ps1ac24dc5-2904600?type=pdf), [PLC-RSC-24DC/21](https://www.phoenixcontact.com/en-pc/products/relay-module-plc-rsc-24dc-21-2966171?type=pdf), and [PLC-RSC-24DC/21-21/AEX](https://www.phoenixcontact.com/en-us/products/relay-module-plc-rsc-24dc-21-21-aex-5603678).

## Simulation boundary

The catalog is separate from the 74 editable educational electrical simulation definitions. Catalog rows marked `reference-only` do not claim terminal-level compatibility or runtime behavior. `LRD12` is `contact-only`: its normally closed contact can be represented with the generic overload symbol, but thermal memory, motor-current measurement, and trip curves are not simulated. The electrical component tests cover supported generic models and PLC-to-load integration.

## Requirement gap

The 500-entry source-backed catalog target is **met** with 10225 unique references. The S7-1500 overview is from 2024; S7-1200, ET 200SP, and LOGO! 8 exports are from 2025. Product overviews do not confirm current availability. We did not pad the catalog with inferred suffixes, family names presented as distinct orderable products, or copied third-party lists. Manufacturer references with no editable model remain `reference-only`; a separate electrical model and tests are required before any is represented as a supported simulation device.

## Focused checks

Run `npm run test:industrial-catalog` for uniqueness, minimum provenance, search/filter/paging, sourced product distinctions, and explicit simulation-boundary checks. `npm test` also runs this focused suite and retains all generic component and example-project integration tests.

The Finder import takes exact manufacturer order codes and short product descriptions from the [English BMEcat catalog](https://www.findernet.com/en/worldwide/support/general-catalog/) generated on 2026-09-02. The importer selects industrial relays, contactors, protection, I/O, power supplies, and panel accessories. All Finder entries are reference-only. Run "scripts/import-finder-catalog.ps1 -Archive <Finder ZIP>" from PowerShell to regenerate the data module, then run "node scripts/export-component-bank.js" to regenerate both exports.

The Doepke data comes from the [manufacturer BMEcat export](https://www.doepke.de/en/bmecat/) dated 2026-10-28. The importer selects 16 ETIM classes covering physical panel and field equipment. It retains manufacturer order codes and ETIM class identifiers. Run "scripts/import-doepke-catalog.ps1 -Archive <Doepke ZIP>" from PowerShell, then run "node scripts/export-component-bank.js" to regenerate both exports.

The [Siemens Unified Comfort overview](https://mall.industry.siemens.com/tstcloud/Api/Catalog/ExportInformation?catalogItemId=UnifiedComfortPanel&lang=en) dated 2025-10-01 provides 24 standard, neutral, hygienic, and hygienic-neutral panel order codes. The HMI category contains 25 references against the initial acquisition target of 500.

The [Siemens S7-1200 G2 CPU ordering table](https://docs.tia.siemens.cloud/r/simatic_s7_1200_g2_manual_collection_enus_20/ordering-information/cpus) supplies eight additional standard and fail-safe CPU order codes. The catalog now contains 95 PLC controller references against the initial acquisition target of 1,000.

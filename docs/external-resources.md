# External resources

The only configured external resource is the GitHub project repository provided by the stakeholder. It appears in Help with a confirmation step before opening a new tab. `src/resources.js` currently holds a static approved list and rejects non-HTTPS URLs, unlisted hosts, and paths that do not match the approved record.

The requested administrator workflow (add/edit review, domain ownership validation, link checking, localized descriptions, broken-link reports, and access audit history) is not implemented. No PLC vendor, standards, or training links have been invented or approved.

# AdigunSPs in 2 minutes

AdigunSPs is an educational PLC editor and simulator. The simulator has no physical PLC connection.

1. Open the AdigunSPs website. Choose **Continue as guest** if prompted. The top bar counts down four minutes; after that, sign in or create an account to continue editing.
2. To sign in, open the profile icon and enter your email and password. To create an account, select **Create account** and confirm the address from your email. Use **Forgot password?** to receive a password recovery email.
3. Select **Examples** on the toolbar and open an example, or select **New** to start an empty project.
4. In **Program Main**, inspect the example's tags and logic. Toggle the inputs named in **How to test**, then use **Run** for repeated scans or **Step** for one scan. Read the output and **Issues/Diagnostics** before editing.
5. Open **Components / Schematic** to inspect a part's named pins and source in **Properties**. Use **Connect wire** to pick two terminals, add route bends on the canvas, and **Validate** to review the drawing.
6. Open **HMI**, add a **Switch** for a BOOL input and a **Lamp** for a BOOL output, and bind each widget to its project tag in **Properties**. Run again and verify both respond.
7. Use **Pause** or **Reset** to end the test. Save signed-in work to the cloud or download **Save locally (JSON)**. Voltage, current, and RPM are not modeled; the app does not control physical hardware.
8. Guest work is temporary in this tab. Use **Project manager** for saved projects and recovery snapshots.

Press **Ctrl+K** to search actions. Open **Help** in the top menu for the full guide, safety notes, and guided tour.
